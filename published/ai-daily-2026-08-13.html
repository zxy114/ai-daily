1. DeepSeek V4-Pro 0813 结束预览正式 GA，价格将"大幅上调"

影响范围：全球开源/闭源大模型竞争 基础模型 2026-08-12/13

核心事件：DeepSeek 在官方 API 文档与价格页将旗舰模型版本号悄然替换为 DeepSeek-V4-Pro-0813，OpenRouter 模型页面同步显示该 build 为 GA 版；V4-Pro 自 4 月发布后近四个月的预览状态结束。API 端名称 `deepseek-v4-pro` 不变，老用户无需改动集成。

关键数据：支持 1M tokens 上下文窗口与最高 384K 输出；现行价格仍为输入 $0.435/输出 $0.87 per 1M tokens（缓存命中 $0.0036）；DeepSeek 在 API 定价页显著位置提示"整体 API 价格预计将有较大幅度上涨"。据传官方群评测，0813 在 Terminal-Bench 2.1、Cybergym、DeepSWE、AutomationBench 等智能体基准上已超过 Claude Opus 4.8。

影响范围：中国大陆开源/闭源大模型竞争的"价格锚"再次上移；OpenRouter、Hacker News 等英文社区热度同步飙升。

后续动作：DeepSeek 尚未发布正式 changelog 与新权重；0813 权重是否会同步推送 Hugging Face、是否配套论文尚待官方表态。V4-Flash 已于 7/31 先于 Pro 毕业为 GA。

解读：这是一次典型的"先涨价格、先做模型"的渐进式商业化节奏：在 ChatGPT/Claude/SpaceXAI 等海外对手普遍上调 API 价格的环境下，DeepSeek 选择以预览 GA + 价格预警的方式向市场传递"接下来会更贵"的信号，同时保留现价窗口为开发者迁移锁定期。

2. xAI 发布 Grok 4.6：智能指数 61 与 GPT-5.6 Sol 持平，输出价仅 1/5

影响范围：前沿模型竞争 + 企业/开发者 API 选型 前沿模型 2026-08-12

核心事件：xAI 正式上线 Grok 4.6，定位"长任务智能体 + 更复杂的编程/知识工作"，官方称在多项 agentic coding 与知识工作基准上达到前沿水平。已在 Grok Build、Cursor、xAI API 上线，并通过 OpenRouter、Vercel、Cloudflare 等渠道分发。

关键数据：Artificial Analysis Intelligence Index 得分 61，与 GPT-5.6 Sol 打平，仅次于 Claude Opus 5 与 Claude Fable 5；上下文窗口维持 500K tokens（两代未涨）；价格维持 Grok 4.5 水平——$2/1M 输入、$6/1M 输出，仅为 GPT-5.6 Sol（$5/$30）的约 1/5。Long-horizon AA-Briefcase Elo 1577（"Fable 5 级"）。

后续动作：Elon Musk 已透露 4.7 路线图（2.1 万亿参数），并已上线 "Grok Bot" 智能体队友产品对标 ChatGPT Work；Cursor 首周双倍用量补贴开发者迁移。

解读：Grok 4.6 的"杀手锏"不是单项跑分第一，而是"前沿级能力 + 五分之一价格"组合拳；SpaceXAI 以低价正面冲击 GPT-5.6 Sol、Claude Opus 5 的企业 API 预算，标志着前沿模型层从"性能竞赛"转入"性能 × 价格"的二维竞赛。对国内厂商的启示是：智能体代码场景下的"低 Token 单价"已经成为海外大模型营销标配。

3. Anthropic 启用 Claude 隐形水印，欧盟透明度义务触发"布鲁塞尔效应"

影响范围：全球生成式 AI 合规与内容溯源 合规 / 内容溯源 2026-08-11/12

核心事件：Anthropic 在帮助中心公布：自 8 月 2 日起发布的 Claude 新模型默认对生成文本嵌入"机器可识别、人眼不可见"的水印，对图片等文件附数字签名来源元数据，范围覆盖全球用户（不限于欧盟）。这一时间节点恰好对齐 8 月 2 日生效的欧盟 AI 法案第 50 条透明度义务。

关键数据：法案要求"生成式 AI 系统输出内容以机器可读格式标记为人工生成/操纵"，技术方案须满足"有效、可互操作、稳健、可靠"四项标准；签署《AI 生成内容透明度行为准则》的提供方需在 2027-02-02 前实现水印检测机制的互操作，并向媒体/监管/事实核查机构免费开放检测工具。

影响范围：中国《标识办法》对文本水印仅为"鼓励"而非"强制"，境内输出到欧盟可能直接违反强制水印义务；中国 AI 企业检测工具对外可获取性和互操作方面目前几乎"没有声音"。

后续动作：Anthropic 尚未公开水印检测工具；预计在下一次技术文档更新中说明检测机制。欧盟委员会已于 7/20 发布第 50 条最终指南，明确"仅有标记、无检测手段"不足以构成合规。

解读：这是继 GDPR 后又一个"布鲁塞尔效应"案例——一家美国公司按欧盟规则对全球生效。法条第 50(2) 条同时要求"标记 + 检测互操作"，前者易、后者极难；这意味着全球 AI 内容溯源标准的制定权短期内事实上仍掌握在 Anthropic/OpenAI 这类先动玩家手中。

来源：中国新闻网/扬子晚报 · 茉莉花新闻网（转载虎嗅） · Anthropic 帮助中心

解读：面壁智能的"密度定律（DensingLaw）"——"达到特定智能水平所需参数量每 3.5 个月下降一半"——是端侧 AI 商业逻辑的核心理论支撑，与传统云端 Scaling Law 形成互补叙事。这是国内"小参数、强工程"路线最具代表性的资本化样本。

11. MIT Sloan：AI 数据中心电力需求或将拖累全球 2°C 气候目标

核心事件：MIT Sloan 教授 John D. Sterman 在学院官网发文指出，AI 数据中心的电力需求高速增长可能在不进行强有力气候政策的前提下，推迟全球升温控制在 2°C 以下的窗口期；技术承诺无法单独解决问题。

关键数据：文章提出需以"有意义的碳定价 + 效率/可再生能源激励 + AI 完整影响披露"三项政策组合拳应对；电力供需缺口是 AI 时代气候治理的核心瓶颈之一。
