DeepSeek V4.1 Flash 正式发布：原生多模态 + MIT 权重开源

HOT 模型
📅 2026-09-10 · 来源：DeepSeek API Docs · Hugging Face · DeepSeek News
核心事件
DeepSeek 正式发布 V4.1 Flash 多模态模型，开放 API（model 名为 `deepseek-flash`）并同步在 Hugging Face 以 MIT 协议开源权重。模型为 552B 参数 MoE，采用全新的 Causal Encoder-Decoder 非对称架构：prefill 阶段激活约 8B，decode 阶段激活约 16B。
关键数据
552B MoE ／ 输入激活 ~8B ／ 输出激活 ~16B；原生支持文本+图像（DeepSeek-ViT 视觉编码器+投影器）；KV cache 相比前代压缩到约 1/4 HBM、1/8 SSD；最大上下文 1M tokens；上下文最长可比原 V4 Flash 提升 ~437x。
影响范围
进一步抬升中国开源多模态的水位线；为 DeepSeek V4.1 Pro 与科创板 IPO 做产品铺垫；中端价位 API 市场（GPT-5 mini / Claude Haiku）将持续承压；本地化部署门槛大幅降低。
后续动作
V4.1 Pro 预计随后发布（Beta 名 `deepseek-v4.1-flash-expires-on-0910` 已结束）；Pro 上市前，V4 Pro 请求将自动路由到 V4.1 Flash 并按 Flash 价计费；同步推动私有化部署与行业落地合作。
解读分析
"非对称激活 + 超低 KV cache"是 DeepSeek 给出的"小而强"新公式。它实际上承认了一件事：推理成本里 decode KV cache 才是真正的瓶颈，而不是模型参数量。这种结构对 Agent、长上下文、视频/多模态工作流特别友好。配上 MIT 开源，V4.1 Flash 可能成为 2026 下半年最被本地化部署社区拿来做"端到端业务代理"的型号。
