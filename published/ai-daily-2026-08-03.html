Agent 团队 GLM-5.2 AI 编程

贾扬清再创业：Intent Lab + Fleet 自主 Agent 团队，将 GLM-5.2 推理速度提升 534%

智东西 / 36 氪 / 新浪科技 / PANews · 2026-07-29/30 · 36Kr
前阿里云副总裁、Lepton AI 创始人贾扬清 7 月 29 日宣布成立 Intent Lab，推出自主 Agent 团队"Fleet"。与传统编程 Agent 不同，Fleet 试图承担完整工程团队工作：理解需求、设计架构、协调任务、编写代码、测试验证、持续改进。早期成果三项：(1) 重新设计 TensorRT-LLM 代码，GLM-5.2 推理速度提升 534%（达 647 token/s）；(2) 单条 prompt 从零构建兼容 SQLite 行为的数据库，8720 万输出 token 通过 600 万项验收测试，开源模型成本约 350 美元；(3) AgentFS 分布式文件系统，目录状态查询达 EFS 的 626 倍。
核心事件贾扬清再创业 Intent Lab + Fleet 自主 Agent 团队，定位"AI 写代码 → AI 造系统"
关键数据GLM-5.2 推理 +534%；SQLite 重建 600 万项测试通过，成本 ~350 美元；AgentFS 部分性能 ×626
影响范围AI 编程从"工具替代"升级到"团队替代"；传统软件工程的分工模式面临重构
